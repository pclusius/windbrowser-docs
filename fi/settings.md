# Asetukset

Kaikki asetukset ovat hampurilaisvalikossa.

![Menu](../docs/img/menu.png){ width=320 }

| Asetus | Merkitys |
|---|---|
| **Add new forecast tile**, aluerivit | Katso luvut **Ensimmäinen käynnistys** ja **Alueet** |
| **Update all active areas** | Käynnistää päivityksen heti (näkyy, kun alueita on vähintään yksi) |
| **Routing** | Reitit, passage-suunnitelmat ja tallennetut suunnitelmat; katso luku **Reititys** |
| **Show the no-go zone of weather routing** | Näyttää vyöhykkeen (maa ja sen viereinen rannikko), jonka yli sääreititys ei kulje; katso luku **Reititys** |
| **Export GRIB2 of active tiles to Downloads** | Kopioi jokaisen aktiivisen alueen uusimman raakamuotoisen GRIB2-tiedoston Downloads-kansioon alueen numero nimessä |
| **kn / m/s** | Nopeusyksikkö, oletuksena solmut. Tuulinuolet ovat aina solmuina |
| **Wind colours**, **Wind barbs** | Kytke kukin kerros päälle tai pois |
| **Grey land** | Poista valinta, jos haluat näyttää vain rantaviivan |
| **UI Color theme** | Automaattinen, vaalea tai tumma; napauta vaihtaaksesi. Offline-ohje seuraa sitä |
| **Data limit** | 1–5 GB (oletus 2) |
| **History kept** | 1–14 päivää säilytettäviä ajoja, säädetään liukusäätimellä (otetaan käyttöön, kun suljet ikkunan) |
| **ARPEGE key** | Oma Météo-Francen avaimesi, jota ARPEGE tarvitsee; katso luku **ARPEGE ja Météo-Francen avain** |
| **Update log…** | Katso luku **Päivitykset ja vianetsintä** |
| **Manual** | Tämä ohje (englanniksi), tallennettuna sovellukseen, joten se toimii ilman verkkoyhteyttä |
| **About WindBrowser** | Kiitokset, versio sekä linkit verkossa olevaan ohjeeseen ja PDF-tiedostoon |
| **Clear all tiles** | Poistaa kaiken; kysyy aina ensin |

Veneen ja reitityksen asetukset eivät ole valikossa: ne kuuluvat kuhunkin suunnitelmaan ja ovat kohdassa **Plan a passage…** (luku **Reititys**).

## Varmuuskopiointi

Sovellus osallistuu Androidin varmuuskopiointiin, joten Google-varmuuskopiosta palautettu uusi puhelin saa takaisin asetuksesi, alueet (aluelistan), reitit, polaarit, tallennetut suunnitelmat ja reititysasetukset. Ladattuja ennusteajoja ja päivitysloki eivät ole mukana; ne ladataan uudelleen, mutta historia alkaa alusta.
