# Settings

All settings are in the hamburger menu.

![Menu](img/menu.png)

| Setting | Meaning |
|---|---|
| **Unit** | Knots (default) or m/s. Barbs are always in knots |
| **Wind colours / barbs** | Choose colour layer, barbs or both |
| **Grey land** | Turn the grey land fill off to show only the shoreline |
| **Data limit** | 1–5 GB |
| **History** | 1–14 days of runs to keep |
| **Export GRIB** | Copies the newest raw GRIB2 of every active tile to Downloads, with the tile number in the name (Android 10 and newer) |
| **Theme** | Automatic, light or dark; tap to cycle |
| **Update log…** | See [Updates](updates.md) |
| **About WindBrowser** | Credits and version |
